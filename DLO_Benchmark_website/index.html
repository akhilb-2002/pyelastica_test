Deformable Linear Object (DLO) Benchmarks

Kinematic configurations for alphabet-inspired target shapes

This tool generates precise, continuous nodal configurations for 1D deformable objects (ropes, cables). It faithfully mirrors the reference Python pipeline, constructing an ideal centerline from geometric primitives (lines, arcs, and sine curves). The path is then resampled into exactly N uniformly spaced discrete nodes, scaled to a specific target arc length, and translated to a standardized origin. These rigid geometric constraints ensure consistency for use in physics simulations, path planning, and robotic manipulation benchmarks.
